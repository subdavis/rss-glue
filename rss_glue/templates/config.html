Config Format

Enter a list of feed objects:

[
  {
    "id": "unique-id",
    "type": "rss",
    "name": "Feed Name",
    "url": "https://example.com/feed.xml",
    "limit": 50,
    "cooldown_minutes": 30
  },
  {
    "id": "merged-feed",
    "type": "merge",
    "name": "Combined Feed",
    "sources": ["unique-id", "other-id"],
    "limit": 100
  },
  {
    "id": "reddit-feed",
    "type": "reddit",
    "name": "r/selfhosted",
    "subreddit": "selfhosted",
    "listing_type": "top",
    "time_filter": "week",
    "limit": 20
  }
]

Validation Rules

  • Feed IDs must be unique and contain only letters, numbers, hyphens, and underscores
  • RSS feeds require a valid http/https URL
  • Merge feeds must reference existing feed IDs in sources
  • Circular dependencies are not allowed
  • Limit must be between 1 and 1000
  • cooldown_minutes is optional (defaults to global setting), must be 0-10080 minutes
